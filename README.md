# Atelierul fișei disciplinei

Pagină de lucru pentru scrierea rezultatelor învățării dintr-o fișă a disciplinei, folosită în modulul de psihopedagogie medicală de la UMF „Grigore T. Popa” Iași.

Pagina: https://riliescu.github.io/atelier-fisa-disciplinei/

## Ce face

- compune un rezultat al învățării după formula: Studentul + verb observabil + conținut + context sau criteriu;
- arată nivelul verbului în taxonomia lui Bloom revizuită (Anderson și Krathwohl, 2001) și propune nivelul din piramida lui Miller (1990), cu probele și metodele potrivite;
- strânge rezultatele fiecărei grupe într-o matrice (metodă, probă, moment, pondere, rândul din Anexa 2 ARACIS), cu verificări;
- notează întrebările și ideile din sală.

## Unde se păstrează datele

Pagina rulează în întregime în browser și nu trimite date nicăieri. Datele rămân în memoria browserului de pe calculatorul folosit. Butonul „Fișier de date” le salvează și într-un fișier `.json` ales de utilizator, actualizat la fiecare modificare (Chrome și Edge); „Deschide date” încarcă un astfel de fișier, iar „Descarcă copie” salvează o copie.
